## 발견해서 고친 것

1. **텍스트 대비 부족 (접근성)**: 캡션과 라벨에 쓰던 `dim`(#51565a)이 검은 배경에서 2.83:1로 WCAG AA 기준(4.5:1)에 못 미쳤습니다.
   → 읽어야 하는 보조 텍스트용 `subtle`(#80868c, 5.71:1) 토큰을 추가하고 `text-dim`을 모두 `text-subtle`로 바꿨습니다. `dim`은 홈 메뉴의 비활성 항목처럼 장식용으로만 남겼습니다.
2. **모바일 메뉴 포커스**: 메뉴를 열어도 키보드 포커스가 햄버거 버튼에 남아 있었습니다.
   → 열면 첫 메뉴 링크로 포커스를 옮기고, Esc로 닫으면 버튼으로 되돌립니다.
3. **OG 이미지 한글 줄바꿈**: 제목이 단어 중간("사 / 이트")에서 끊겼습니다.
   → `word-break: keep-all`을 적용했습니다.
4. **(TASK-19 중) 홀수 개 카드 그리드의 빈 칸**: 마지막 카드가 한 줄을 다 차지하도록 수정했습니다.

## 참고 (지금은 수정하지 않음)

- **홈 메뉴의 hover 효과는 마우스 전용**: 키보드로 이동하면 링크는 동작하지만 이미지 미리보기는 나오지 않습니다. Originkit 원본 동작입니다.
