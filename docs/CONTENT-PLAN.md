## 3. 케이스 스터디 구조 맞추기

포트폴리오의 모든 프로젝트는 같은 순서로 쓰여 있습니다. 사이트 템플릿도 이 순서에 맞춥니다.

| 포트폴리오 | 지금 사이트 | 바꿀 것 |
| --- | --- | --- |
| Overview (기간, 성과, 구성) | 메타 정보 + 요약 | 성과 3~4줄 하이라이트, 팀 구성(직군별 인원) 추가 |
| Background (통계 + 출처) | 개요 | 숫자 + 출처 표시 |
| User Interview (응답 비율 + 조사 대상) | 문제의 항목들 | 조사 대상·표본 수를 함께 표시 |
| Problem | 문제 | 유지 |
| Hypothesis | 없음 | **새 섹션** |
| Metrics (지표 이름 + def.) | 결과 지표(값만) | **지표 정의**를 먼저 보여주고, 결과에서 같은 지표의 값을 채움 |
| Action & Result | 과정, 결과 | 유지 |
| Failure Analysis · Insight | 회고 | **반복 루프**: 결과 → 실패 분석 → 인사이트 → 개선 액션 → 재결과 |
| AS-IS / TO-BE 플로우 (포도티켓) | 없음 | **플로우 비교** 블록 |
