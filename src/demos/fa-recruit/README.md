# 위촉 사전 진단 시뮬레이터 · 공개 데모

포트폴리오의 `/demo/fa-recruit`에서 여는 FA 위촉 사전 진단 시뮬레이터 데모입니다.
원본은 사내용(비밀번호 잠금)이라, 화면 코드를 이 앱 안에 복사하고 **사내 기준 문구만 대외비로 가렸습니다.**
판정 로직은 원본 그대로라 적격 · 심사 대상 · 조건부 · 불가 흐름이 모두 동작합니다.

- 원본: 로컬 `fa-recruit-simulator` 저장소 (비공개)
- 복사한 커밋: `1eac89c` (커밋되지 않은 작업 트리 변경은 제외) · 복사한 날: 2026-09-29

## 원본과 다른 점

이 저장소는 공개라서 원문이 커밋되면 안 됩니다. 그래서 화면에서 가리는 것만이 아니라 **데이터 자체를 바꿨습니다.**

- **대외비 치환**: 제한 사유 이름 · 질문 · 기준 설명, 서류 · 이행 가이드, 특수조건 안내, 재입사 안내, 판정 설명, 말소 FAQ를 원문 대신 `대외비 대외비 …` 더미로 바꿨습니다 (원문 줄 수와 길이만 비슷하게 맞춤). 3지선다 선택지는 `해당 · 기준 이하 / 초과`로 일반화했습니다.
- **블러 표시**: 화면은 더미 구간만 흐리게 그리고 🔒 대외비 배지를 붙입니다(`Confidential`). 복사 · 엑셀 · 이미지 내보내기에는 `대외비` 글자가 그대로 나갑니다.
- **남긴 것**: 판정 로직과 기준 숫자(코드 속 상수), 협회 공개 기준인 시험 · 교육 유효기간 계산, 서류 이름, 화면 제목과 라벨.
- **주석 전부 삭제**: 원본 주석에 사내 매뉴얼 인용 · 한도 · 결재 절차가 있어 데모 코드의 주석을 모두 지웠습니다.
- **접근 잠금 제거**: 비밀번호 화면과 비밀번호 해시(원본 주석에는 평문도 있음)를 가져오지 않았습니다. Supabase 연결 파일 · 테스트도 뺐습니다.
- **사내 자료 교체**: 양식 PDF · 작성 샘플 6개는 제목만 같은 가상 양식으로, IIMS · 사이버캠퍼스 주소는 `#demo-internal-system`으로 바꿨고 로고는 지웠습니다.
- **가상 대상자**: 단체 진단은 브라우저에 저장된 명단이 없을 때 판정별 가상 대상자 5명(적격 · 심사 대상 · 불가 · 조건부 · 진단 중)으로 시작합니다.

원본을 다시 복사할 때는 `node scripts/fa-recruit-redact.cjs .`로 치환 · 주석 삭제를 다시 한 뒤 (파일별 추가 치환은 스크립트 밖에서 손으로 했으니 README의 목록과 대조), 빌드 결과(`.next/static`)에 원문 문구가 없는지 검색해 확인합니다.
