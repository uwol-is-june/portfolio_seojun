# 보장분석 · 공개 데모

포트폴리오의 `/demo/coverage`에서 여는 보장분석 서비스 데모입니다.

- 원본: 로컬 `incar_ca_test` 저장소 (비공개)
- 복사한 커밋: `0ab035d` · 복사한 날: 2026-09-29

| 무엇 | 위치 |

## 원본과 다른 점

- `/api/codef/*` 서버 라우트 대신 `mock-api.ts`가 브라우저 안에서 같은 모양으로 응답합니다. 입력값은 어디에도 전송하지 않고, 인증번호 · 비밀번호는 아무 값이나 통과합니다.
- 보험사 · 상품 · 증권번호는 가상 값으로 바꿨습니다. 권장 보장액과 갭 분석 · 점수 계산은 원본 그대로입니다.
- 기존 계정은 SMS/PASS 2차 인증을, 신규 가입은 본인인증 → 회원정보 → 이메일 인증을 원본 순서대로 거칩니다. 보안문자(캡차) 단계는 나오지 않습니다.
- 링크 경로를 `/` → `/demo/coverage`로 옮기고, 오른쪽 아래에 '공개 데모' 표시와 '포트폴리오로' 링크를 붙였습니다.
